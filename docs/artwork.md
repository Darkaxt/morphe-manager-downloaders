# Launcher artwork

The companion launcher foreground retains Morphe Manager's vector artwork from
`MorpheApp/morphe-manager@v1.33.0-dev.17`, resource
`app/src/main/res/drawable/ic_launcher_foreground.xml`. The existing companion's
green download badge is scaled down at its bottom-right corner. The adaptive-icon
background uses Morphe's corresponding `#EEEEEE` background.

The foreground retains its original copyright notice. Morphe branding belongs to
Morphe and is not covered by the repository's GPL license; see
[Morphe branding](https://github.com/MorpheApp/morphe-branding). The badge identifies
this independent companion; it does not change its package or signing identity.
