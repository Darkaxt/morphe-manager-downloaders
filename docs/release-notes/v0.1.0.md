# Morphe Manager Downloaders 0.1.0

Standalone APKMirror downloader for existing Morphe Manager installations.

- Select the companion through LinkSheet for APKMirror links.
- Configure a private HTTPS Byparr API endpoint on first use.
- Choose the required variant, download the original APK/APKM and open it in Morphe Expert mode.
- Endpoint settings persist; failures offer an explicit edit and retry.

The companion uses its own package and signing identity. Your existing Morphe
installation and patch-signing key remain unchanged.

Verified on Android 15: real APKMirror APKM download through Byparr 3.0.4, archive
validation, and import into official Morphe 1.33.0. Phone verification is pending.
Byparr must be reachable from your device. The current APKMirror flow uses
`request.get` over POST `/v1`; upstream POST support is not needed for this flow.

Minimum Android: 8.0. Enable Expert mode in Morphe before using the companion.
