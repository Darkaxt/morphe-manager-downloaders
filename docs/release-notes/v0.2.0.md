# Morphe Downloader 0.2.0

- Use Morphe's launcher artwork with a small download-arrow badge.
- Replace the full window with a compact rounded dialog in light and dark themes.
  Show `Downloading {app name}`, the actual resolution/download/validation status,
  and measured progress beneath the name.
- Add APKPure and APKCombo alongside APKMirror. Preserve requested versions,
  explicit variant choices, source-specific attachment hosts and browser-session
  headers. APKCombo's `noreferrer` policy is respected.
- Validate and share original APK, APKM and XAPK archives with Morphe Expert mode.
- Keep the existing package, signing identity, saved Byparr setting and ObtainX
  upgrade path. Existing Morphe and patched apps are not replaced or resigned.
- Restore the completed result when the window is recreated, instead of processing
  its incoming download link again.

**Uptodown remains pending** until the Byparr browser-action update is available
and live-verified. This release does not handle Uptodown links. POST support alone
does not generate its download button's Turnstile token.

Requires Android 8+, a reachable private HTTPS Byparr endpoint and Morphe Expert
mode. Live APKPure/APKCombo Showly 3.72.0 workflows were verified on the isolated
Android emulator through original-file validation and unchanged readable URI
sharing. Independent updated-phone verification remains pending.

Release build/lint, APK signature, Android lifecycle/URI checks and a signed
0.1.1 -> 0.2.0 upgrade preserving the server setting pass. Source labels identify
real variants; generic First/Second labels exist only in local test fixtures.
