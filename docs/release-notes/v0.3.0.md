# Morphe Downloader 0.3.0

## Uptodown downloads

- Adds Uptodown app/build links to the LinkSheet chooser alongside APKMirror,
  APKPure and APKCombo.
- Uses Byparr's new browser scripting API to let Uptodown generate its own fresh
  download token, while preserving the requested build.
- Checks the successful website response and captured file link before Android
  downloads the original. The archive is validated before sharing it with Morphe.
- Requires an updated Byparr server reporting `custom-post-scripting`. Existing
  servers can continue resolving the other three sources. Keep your saved endpoint.

## Cleaner dialog

- Replaces the ready filename title with the app's name, package ID and version/build,
  following InstallerX's layout. Details come from the downloaded APK's metadata.
- Supports metadata from APKM/XAPK base APKs and previously saved ready downloads.
  Keeps a readable filename fallback if optional metadata is unavailable.
- Renames the Byparr setup buttons to **Cancel** and **Save**.

The app keeps its package and signing identity, allowing an in-place update. It
downloads and shares original files; Morphe remains responsible for patching and
installation. This release includes the existing Morphe icon with download badge,
compact light/dark dialog and actual download status/progress.

Live Uptodown verification downloaded Showly 3.72.0 (build 843) on Android and
confirmed the original bytes through the receiving URI. This does not guarantee
future website challenge acceptance or represent a physical-phone installation test.
