# Morphe Downloader 0.3.1

Download failures now stay in the compact download dialog instead of opening
Byparr server configuration.

## Retry or continue in your browser

- **Retry** starts a fresh resolution for the selected app release or APK variant
  using your saved Byparr server. Expired APKMirror landing links are replaced
  with the selected variant page before resolving again.
- **Open in Browser** opens that source page in an external chooser, excluding
  Morphe Downloader itself to avoid reopening the same download dialog.
- The actual failure message and both actions survive reopening the dialog.
- A failed new request no longer offers an older completed APK as its result.
- Byparr settings remain available through the cog. First-use setup still asks
  for a server when none has been saved, with **Cancel** and **Save** buttons.

The package and signing certificate are unchanged. Update in place through
ObtainX or install the attached APK; your saved server and existing Morphe
installation remain intact.

## APKMirror investigation remains open

This release improves recovery from download failures. It does not fix the
Cloudflare rejection observed at APKMirror's protected download redirect.
Byparr browser-capture attempts for the affected YouTube build did not complete
successfully. **Open in Browser** provides the manual path when automatic
resolution fails. The automatic correction and physical-phone retest remain
pending; no Byparr deployment changes are included.

Verification covers inline failure/retry behavior, dialog recreation, browser
chooser exclusion, metadata presentation, cancellation, release signing, and a
0.3.0 -> 0.3.1 upgrade that preserves the saved server. This release was verified
on an isolated Android emulator; it does not claim a new physical-phone test.
