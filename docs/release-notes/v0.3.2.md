# Morphe Downloader 0.3.2

Morphe Downloader works with Byparr's new transactional browser queue. With the
updated server, page requests wait behind other consumers instead of failing
immediately with “Browser busy” (HTTP 429). No extra setting is required. The
server update supplies this behavior; installing the APK alone does not update
Byparr.

- Cancel removes a waiting page request before it reaches the browser.
- A full server backlog now explains that no page request was submitted and
  offers the existing explicit Retry action. Other 503 failures retain their
  original error classification. Requests are never retried automatically.
- Retry and Open in Browser remain in the standard download dialog; the cog
  opens Byparr settings. Package identity and the signing certificate are unchanged.

Verified against the original deployed endpoint: an Android request queued behind
a held operation resolved the real YouTube APKMirror page, and Android cancellation
removed another request before admission. The signed APK upgrades 0.3.1 in place
while preserving its endpoint. A fresh Showly 3.72.0 Uptodown download passed
archive, package/version/build, exact-byte hash and readable receiving-URI checks
on an isolated Android emulator. Focused contracts and release build/lint passed.

The APKMirror native attachment Cloudflare rejection remains unresolved. Queuing
addresses browser contention; it does not establish a fix for that separate
download failure. Physical-phone patching and installation are not claimed.
