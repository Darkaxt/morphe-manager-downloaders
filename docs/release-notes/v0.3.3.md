# Morphe Downloader 0.3.3

The download dialog now displays live Byparr queue feedback: your position among
waiting requests and the number queued ahead. Once your request reaches the
browser, the status changes to “Byparr is resolving the download…”. This requires
Byparr's deployed `custom-post-scripting-queue-feedback` update; older servers
retain the ordinary status display.

- Download sizes automatically scale to readable B/KB/MB/GB units instead of
  showing large KB numbers. Transfer progress remains based on actual bytes.
- Feedback belongs to the current browser request and stops on completion or
  cancellation. Missing feedback never causes automatic retries or false success.
- Builds now use JDK 21 while retaining Java/Kotlin target 17 for Android.
  Package identity, signing certificate and saved Byparr settings are preserved.

Verified against the original deployed Byparr endpoint: the Android caller's
actual queue position moved from 3 to 2 under concurrent consumer load. Cancelling
it removed its live request ID before browser admission; neither cancelled target
was visited. Dialog checks cover waiting, active resolution, real byte progress,
and cancellation followed by recreation.

The signed APK upgrades published 0.3.2 in place while retaining the configured
endpoint. A fresh Showly 3.72.0 Uptodown download passed package/build metadata,
exact-byte hashes and receiving-app URI readability checks on an isolated emulator.
Focused contracts, release packaging and lint passed.

APKMirror's separate native attachment Cloudflare rejection remains unresolved.
Queue feedback describes browser admission and does not claim to fix that failure.
